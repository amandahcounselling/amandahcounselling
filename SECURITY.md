# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the `main` branch of this template repository.

If you fork this project for your practice, you are responsible for keeping your fork updated and securing your own deployment, form providers, and third-party integrations configured in `src/config/site.ts`.

## Reporting a vulnerability

If you discover a security issue in this template (not in your fork-specific configuration or hosting setup), please report it privately:

- Open a [GitHub Security Advisory](https://github.com/brysonbest/counselling-website-template/security/advisories/new) on this repository, **or**
- Email the maintainer if you prefer not to use GitHub advisories.

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- Any suggested fix, if you have one

Please do **not** open a public issue for undisclosed security vulnerabilities.

We aim to acknowledge reports within a few business days and will work with you on a reasonable disclosure timeline.
